# Seyir · Türk müziği öğrenme oyunu

Türk müziği öğrencilerinin Arel-Ezgi-Uzdilek sistemindeki komaları, perdeleri, dörtlü-beşlileri ve makamları oyun oynayarak öğrenmesi için hazırlanmış bir web uygulaması.

**Oynamak için:** https://burakbastas.github.io/perde-oyunu/
